# 行为准则

## 我们的承诺

我们希望 Mewte 成为一个任何人都能参与且不受骚扰的项目，无论其年龄、体型、残障状况、民族、性别认同与表达、经验水平、教育程度、国籍、外貌、种族、宗教、性取向或社会经济地位如何。

本文档遵循 [Contributor Covenant 2.1 版](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)的精神。本文未涉及之处，以该文档为准。

## 期望的行为

- 保持尊重和耐心。先假定对方出于善意，在往最坏处想之前先问一问。
- 针对工作本身提出反馈，而不是针对个人。说明你的理由。
- 虚心接受反馈，出现错误时坦然承认。
- 使用友好、包容的语言。我们当中许多人并不是在用母语写作。
- 把社区的健康发展置于赢得争论之上。

## 不可接受的行为

- 骚扰、侮辱、人身攻击或政治攻击，以及贬损性的言论。
- 带有性意味的语言或图像，以及任何形式的不受欢迎的性关注。
- 未经本人明确许可，公开他人的私人信息，例如住址或电子邮箱。
- 蓄意恐吓、跟踪，或在被要求停止后仍反复联系对方。
- 在职业场合中不恰当的任何其他行为。

## 适用范围

本准则适用于项目的所有空间：Issue、Pull request、Discussion、代码审查，以及项目使用的任何其他渠道。当有人在公开场合代表本项目时，本准则同样适用。

## 举报

如果你遭遇或目睹了不可接受的行为，请通过维护者 [GitHub 个人主页](https://github.com/BlackHole1)上的联系方式私下举报。请不要为此提交公开的 Issue。

请说明发生了什么、发生在哪里，并尽可能附上链接或截图。举报会以保密方式处理，未经举报人同意，不会透露其身份。

## 执行

维护者会审查每一份举报，并根据造成的伤害程度采取相应的措施：

1. **纠正**：私下说明哪些行为不恰当以及原因。
2. **警告**：发出明确警告，并说明继续此类行为的后果。
3. **临时封禁**：在一定期限内禁止与项目进行任何互动。
4. **永久封禁**：从项目的所有空间中移除。

对于不符合本准则的评论、提交、代码、Issue 及其他贡献，维护者可以将其删除、编辑或拒绝。维护者与其他所有人一样，须遵守同样的标准。
