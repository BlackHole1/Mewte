# 行為準則

## 我們的承諾

我們希望 Mewte 是一個人人都能參與而不受騷擾的專案，不論年齡、體型、身心障礙、族裔、性別認同與性別表現、經驗多寡、教育程度、國籍、外貌、種族、宗教、性傾向或社會經濟地位。

本文件遵循 [Contributor Covenant 2.1 版](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)的精神。本文未提及之處，以該文件為準。

## 期望的行為

- 保持尊重與耐心。先假設對方出於善意，在往最壞處想之前先開口詢問。
- 回饋應針對事情本身，而非針對個人。請說明你的理由。
- 虛心接受回饋，犯錯時坦然承認。
- 使用友善、包容的語言。我們當中有許多人並非以母語書寫。
- 將社群的健康置於贏得爭論之上。

## 不可接受的行為

- 騷擾、侮辱、人身或政治攻擊，以及貶低他人的言論。
- 帶有性意味的語言或圖像，以及任何形式不受歡迎的性關注。
- 未經對方明確同意，公開其私人資訊，例如住址或電子郵件地址。
- 蓄意恐嚇、跟蹤，或在對方要求停止後仍反覆聯繫。
- 其他在專業場合中不恰當的行為。

## 適用範圍

本準則適用於專案的所有空間：issue、pull request、討論、程式碼審查，以及專案使用的任何其他管道。當有人公開代表本專案時，本準則同樣適用。

## 回報

如果你遭遇或目睹不可接受的行為，請透過維護者 [GitHub 個人檔案](https://github.com/BlackHole1)上的聯絡方式私下回報。請不要為此開公開的 issue。

請說明發生了什麼事、發生在哪裡，並盡可能附上連結或螢幕截圖。回報會以保密方式處理，未經回報者同意，不會透露其身分。

## 執行

維護者會審視每一則回報，並依造成傷害的程度做出相應的處置：

1. **糾正**：私下說明哪些行為不恰當以及原因。
2. **警告**：明確提出警告，並說明持續該行為的後果。
3. **暫時停權**：在一定期間內禁止與專案互動。
4. **永久停權**：從專案的各個空間中移除。

維護者可以移除、編輯或拒絕不符合本準則的留言、commit、程式碼、issue 及其他貢獻。維護者與所有人適用相同的標準。
