# 行動規範

## 私たちの約束

私たちは、年齢、体型、障害、民族、性自認と性表現、経験のレベル、学歴、国籍、容姿、人種、宗教、性的指向、社会経済的地位にかかわらず、誰もがハラスメントを受けることなく参加できるプロジェクトとして Mewte を運営したいと考えています。

この文書は [Contributor Covenant バージョン 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) の精神に沿っています。この文書に定めのない事項については、Contributor Covenant を拠り所とします。

## 期待される行動

- 敬意と忍耐をもって接してください。相手に悪意はないものと考え、最悪の事態を想定する前にまず尋ねてください。
- フィードバックは人ではなく、成果物に対して行ってください。その理由も説明してください。
- フィードバックは素直に受け止め、誤りがあったときはそれを認めてください。
- 誰もが歓迎されていると感じられる、包摂的な言葉を使ってください。私たちの多くは、母語ではない言語で書いています。
- 議論に勝つことよりも、コミュニティの健全さを優先してください。

## 許容されない行動

- ハラスメント、侮辱、個人攻撃や政治的な攻撃、相手を貶める発言。
- 性的な言葉や画像の使用、およびあらゆる種類の望まれない性的な関心。
- 住所やメールアドレスなど、他者の個人情報を本人の明示的な許可なく公開すること。
- 意図的な威嚇、つきまとい、やめるよう求められた後も繰り返される接触。
- その他、職業上の場にふさわしくない行為。

## 適用範囲

この規範は、Issue、プルリクエスト、ディスカッション、コードレビュー、その他プロジェクトが利用するあらゆるチャンネルなど、プロジェクトのすべての場に適用されます。公の場でプロジェクトを代表する場合にも適用されます。

## 報告

許容されない行動を経験または目撃した場合は、メンテナーの [GitHub プロフィール](https://github.com/BlackHole1)に記載されている連絡先を通じて、非公開でメンテナーに報告してください。この件で公開の Issue を作成することはお控えください。

何がどこで起きたのかを説明し、可能であればリンクやスクリーンショットを添えてください。報告は秘密を守って取り扱われ、報告者の身元が本人の同意なく共有されることはありません。

## 執行

メンテナーはすべての報告を確認し、生じた被害の程度に応じて対応します。

1. **是正**: 何が不適切だったのかを、その理由とあわせて非公開で伝えます。
2. **警告**: 行動が続いた場合の措置を示した、明確な警告を行います。
3. **一時的な参加禁止**: 一定期間、プロジェクトでのやり取りを禁止します。
4. **永久的な参加禁止**: プロジェクトの場から排除します。

メンテナーは、この規範に従わないコメント、コミット、コード、Issue、その他のコントリビューションを削除、編集、または却下することがあります。メンテナーにも、他のすべての人と同じ基準が適用されます。
